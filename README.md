# Literature to Lecture · 从文献到讲义

将科学文献整理为忠于原文的教学讲义、单篇论文导读或综述，默认交付配图 PDF，并保留可编辑源文件。更适合人工智能、计算机科学、物理等理科与技术领域，但不限于这些领域。

- 获取并核查全文，保留可追溯来源。
- 通过具体算例讲清方法、公式、图表。
- 检查原文覆盖、读者理解和文档排版。

**使用：** 将本技能添加到支持技能指令的助手中，提供论文或主题，并说明读者基础、语言与输出格式。详见 [SKILL.md](SKILL.md)。

---

Turn scientific papers into source-faithful lectures, single-paper handouts, and surveys as illustrated PDFs with editable sources by default. Best suited to science and technical fields such as artificial intelligence, computer science, and physics, but not limited to them.

- Retrieve and inspect full texts with traceable sources.
- Explain methods, formulas, figures, and tables with worked examples.
- Check source coverage, reader comprehension, and document layout.

**Use:** Add this skill to an assistant that supports skill instructions, provide a paper or topic, and specify the audience, language, and output format. See [SKILL.md](SKILL.md).

附带 Python 3 文献记录核查脚本；它检查证据记录，不证明科学结论正确或文献覆盖穷尽。  
Includes a Python 3 corpus audit script; it checks evidence bookkeeping, not scientific correctness or exhaustive coverage.
